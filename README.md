# John Jay College Economics: Student Success & Graduate Pathways

A password-protected design prototype for a John Jay College Department of Economics page covering internships, graduate school preparation, faculty research, seminars, publishing, scholarships and mentorship. Developed by Mark G. Sheppard. Not an official jjay.cuny.edu page.

- `index.html`: main page
- `opportunities.html`: full, filterable list of internships, research assistant jobs and programs (updated November 2026)
